# Смета за 5 минут

Учебное веб-приложение для быстрого создания смет для клиентов.

Планируемые возможности:

- Создание сметы для клиента.
- Автоматический расчёт стоимости.
- Применение скидки.
- Расчёт НДС.
- Выбор валюты.
- Сохранение сметы в PDF.

Проект будет работать в браузере на обычных HTML, CSS и JavaScript, без npm и дополнительных пакетов.

Сейчас создана только документация. Само приложение пока не реализовано.
## Отчёт по домашнему заданию №3

### Реализованные функции

1. **Сумма прописью** — отображает итог сметы словами, включая тиыны. Работает на странице, в PDF и в тексте WhatsApp. Требования: `specs/001-summa-propisyu.md`.
2. **История смет** — позволяет сохранять несколько смет, просматривать их список и открывать ранее сохранённые сметы. Требования: `specs/002-istoriya-smet.md`.
3. **Поиск по истории смет** — фильтрует историю по номеру сметы или имени клиента по мере ввода текста. Требования: `specs/003-poisk-po-istorii-smet.md`.

4. **Управление историей смет** — переименование записей, удаление с подтверждением и четыре режима сортировки: сначала новые/старые, сумма по возрастанию/убыванию. Поиск работает по номеру и клиенту; названия остаются только в истории. Суммы сравниваются численно без конвертации валют. После обновления страницы выбран режим «Сначала новые». Требования: `specs/004-upravlenie-istoriey-smet.md`.

### Проверки

- Сумма прописью проверена для целых сумм, скидки, НДС, тиынов и переключения валюты.
- Проверено отображение суммы прописью в PDF и WhatsApp.
- Проверено сохранение истории после F5, открытие сметы, сохранение нескольких смет и сохранность истории после очистки черновика.
- Поиск по номеру сметы проверен в браузере.
- Дополнительные проверки поиска по имени клиента, пустому запросу и отсутствию совпадений следует подтвердить перед окончательной сдачей.

- Управление историей: пройдены 32 автоматические проверки в имитации DOM/localStorage (`specs/003-search-tests.cjs`), включая сортировку, поиск, сохранение, переименование, удаление и регрессии расчётов.
- Пользователь подтвердил в браузере отмену удаления, удаление выбранной копии, сохранение после F5 и неизменность черновика.
- Сортировка **не проверена в браузере**: требуется проверить все режимы с поиском и изменением истории, сброс после F5, клавиатуру, фокус и ширину 360 px. После изменений также вручную проверить PDF, копирование WhatsApp, расчёты и черновик. Полный отчёт: `specs/004-upravlenie-istoriey-smet.md`.

### Правила проекта

Файл `AGENTS.md` содержит постоянные инструкции для Codex. Перед реализацией новой функции агент создаёт файл требований в `specs/` и ждёт команды «делай».

Добавлено правило на основе реального опыта: если функция не проверена в настоящем браузере, агент должен прямо сообщить об этом и перечислить необходимые ручные проверки. Проверка синтаксиса не заменяет проверку работы сайта.

### Порядок работы

Для каждой функции: требования в `specs/` → проверка требований → команда «делай» → тестирование → Git-коммит.
