# AGENTS.md — Смета за 5 минут

## О проекте

Учебное веб-приложение для быстрого расчёта стоимости услуг и отправки сметы клиенту. Работает локально в браузере.
## Правила
- Работай только в текущей папке проекта.
- Используй только HTML, CSS и обычный JavaScript без дополнительных библиотек, чтобы сайт работал без интернета.
- Пиши интерфейс и сообщения пользователю на русском языке.
- Не изменяй работающие функции, если этого не требует задача.
- Данные сметы сохраняй локально в браузере; не отправляй их на сервер.
- Сохраняй удобство использования на телефоне.
- Денежные суммы отображай понятно: например, 15 000 ₸, без NaN и Infinity.
- Не записывай в файлы проекта пароли, токены и секретные ключи.

## Новая функция
- Для каждой новой функции сначала создай отдельный файл specs/NNN-nazvanie.md с целью, требованиями, примерами, ограничениями и критериями «Готово, когда».
- Покажи мне требования и дождись команды «делай» перед изменением кода.
- Если информации недостаточно, сначала задай вопрос.

## Как проверить
- Проверь примеры и каждый пункт «Готово, когда» из файла требований.
- После изменений проверь, что расчёты, скидка, НДС, валюты, PDF, WhatsApp и сохранение черновика продолжают работать.
- Проверяй, что сайт не показывает NaN и некорректные суммы.
- Если функция не проверена в настоящем браузере, прямо укажи «Не проверено в браузере» и перечисли ручные проверки. Не называй задачу полностью выполненной только на основании проверки синтаксиса или автоматических тестов.

## Git
- Коммит и push делаешь ты, но только после моей проверки и моего «да».
- Перед работой выполни git status. Есть незакоммиченные изменения — скажи и спроси, что с ними делать.
- Сделал шаг или файл требований и проверил сам — остановись. Покажи изменённые файлы (git status --short), напиши, что мне проверить руками, и спроси: «Коммитим?»
- «да» значит только коммит, а не следующий шаг. На «да» выполни по очереди: 1) git add . 2) git commit -m "<короткая подпись по-русски>" 3) git push.
- git remote -v пустой — push пропусти и скажи об этом. Push просит upstream — выполни git push -u origin <текущая ветка>. Push отклонён или просит вход — остановись и покажи ошибку целиком.
- Любая команда git не выполнилась — остановись, покажи ошибку целиком и ничего не обходи.
- Я ответил «нет» или описал ошибку — исправь, проверь снова и снова спроси. Без моего «да» не коммить.
- Историю не переписывай: без git reset --hard и git push --force.

## Большая функция
- Если функцию нельзя сделать и проверить за один раз, добавь в конец specs/NNN раздел «Шаги»: 3–6 шагов по порядку, у каждого [ ].
- У каждого шага: что появится на экране и проверка на 2–3 действия руками.
- Первым ставь шаг, на котором строятся остальные.
- Делай только один шаг за раз. Сделал — отметь его [x] в разделе «Шаги» и действуй по разделу «Git».
- README.md обновляй после последнего шага. Новые файлы тестов не создавай.
