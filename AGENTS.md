# Правила для AI

- Работать только в текущей папке проекта. Не создавать и не изменять файлы за её пределами.
- Использовать обычные HTML, CSS и JavaScript без npm и дополнительных пакетов.
- Сохранять уже работающие функции при внесении изменений.
- Не отправлять пользовательские данные на сервер. Обрабатывать их локально в браузере.
- Обеспечивать удобство использования на телефоне: адаптивную вёрстку, читаемый текст и удобные элементы управления.
- После изменений перечислять сделанные правки и честно сообщать, что проверено, а что не проверялось.
